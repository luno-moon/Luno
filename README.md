# Luno

Luno 是一款 Windows 桌面助手。本仓库只提供可直接安装的 Windows x64 安装包，不提供源码文件。

## 下载

[下载 Luno-windows-0.1.0-x64-Setup.exe](https://github.com/luno-moon/Luno/releases/download/v0.1.0/Luno-windows-0.1.0-x64-Setup.exe)

下载后双击安装包，按照安装向导完成安装即可。

## 功能说明

- 月影魔猫桌面宠物与桌面互动功能
- 灵动岛式桌面信息展示
- 天气信息与城市设置
- 待办事项、提醒、倒计时和日程辅助
- 记账与简单计算工具
- 图片处理与批量图片操作
- 文件整理与批量重命名
- 工作区和常用桌面工具

## 本版本不包含

- PDF 创建、转换、拆分、合并、加密、解密和页面处理
- Word/Excel 转 PDF
- Windows 系统垃圾、缓存和临时文件扫描或删除
